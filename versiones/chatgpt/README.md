# Versión ChatGPT

Aquí va la variante hecha con ChatGPT.

Cuando exista, deja en esta carpeta un front-end que se pueda arrancar con un solo comando documentado en este archivo. Debe consumir los mismos contratos de `docs/contratos-api.md` y conservar el inventario de `docs/DIAGNOSTICO.md`.

Sugerencia de arranque, cuando el código esté:

```bash
cd versiones/chatgpt
npm install
npm run dev
```
